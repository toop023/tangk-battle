# 坦克大战 dApp 游戏开发计划

## 🎯 目标
开发一款类似坦克大战的游戏，部署到 Seeker 手机 dApp Store

## 📱 目标平台
- Solana Mobile Seeker (Android)
- dApp Store 上架
- 支持触屏操作

## 🛠️ 技术栈

### 前端游戏
- **HTML5 Canvas** - 游戏渲染
- **JavaScript** - 游戏逻辑
- **PWA** - 可安装到桌面

### Web3 集成 (可选)
- **Solana Web3.js** - 钱包连接
- **Phantom Wallet** - Seeker 内置钱包
- **SPL Token** - 游戏积分/NFT

### 部署
- **静态托管** - GitHub Pages / Vercel / Netlify
- **或** IPFS + Arweave 永久存储

## 🎮 核心功能

### 第一阶段：基础游戏
- [ ] 玩家坦克控制 (方向键/WASD/触屏)
- [ ] 敌方 AI 坦克
- [ ] 地图障碍物 (砖墙/钢墙/水/草地)
- [ ] 炮弹发射与碰撞检测
- [ ] 基地保护
- [ ] 关卡系统

### 第二阶段：增强功能
- [ ] 道具系统 (护盾/加速/强化炮弹)
- [ ] 多种敌人类型
- [ ] 音效与背景音乐
- [ ] 分数排行榜

### 第三阶段：Web3 功能
- [ ] Solana 钱包连接
- [ ] 游戏积分上链
- [ ] NFT 坦克皮肤
- [ ] 排行榜上链

## 🎨 游戏设计

### 地图元素
| 元素 | 可穿透 | 可摧毁 |
|------|--------|--------|
| 空地 | ✓ | - |
| 砖墙 | ✗ | ✓ (4发) |
| 钢墙 | ✗ | ✗ |
| 水 | ✗ | - |
| 草地 | ✓ | - |
| 基地 | ✗ | ✓ |

### 坦克属性
- 生命值
- 移动速度
- 炮弹速度
- 射击冷却

### 控制方式
- **键盘**: WASD 移动, 空格射击
- **触屏**: 左侧虚拟摇杆移动, 右侧按钮射击
